Diferencia entre Elementos Inline y Block

Elemento (Display: Block) - Ocupa todo el ancho.
Elemento (Display: Inline) - Solo el ancho de su contenido.
Elemento (Display: Inline-Block) - Fluye en línea pero acepta ancho y alto.

Overflow (Visible, Hidden, Scroll, Auto)

Visible: Texto largo que sobresale del límite marcado en la caja.
Hidden: Texto largo recortado automáticamente fuera del área.
Scroll: Muestra barras siempre activas para navegar.
Auto: Agrega barra solo cuando el contenido excede la altura.
